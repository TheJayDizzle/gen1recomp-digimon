# Changelog

All notable changes to Digimon in Kanto are documented here.

## 0.1.4

- Added new Digimon: Sunarizamon, Tortamon and Drimogemon
- Added digivolution paths and requirements for the newly introduced Digimon.
- Edited trainer battles on Route 11
- Edites encounter tables of Diglett's cave abd Route 11
- Corrected the code of every digimon's TM learnset, since they were not able to learn TMs or HMs
- Corrected spelling errors in movesets of Angemon and Ogremon

## 0.1.3

- Added new Digimon: Lalamon, Sunflowmon, Floramon, Kiwimon, Otamamon, Gekomon,
  Impmon, Wizardmon, Sorcermon, Raremon and Mojyamon.
- Added digivolution paths and requirements for the newly introduced Digimon.
- Added Powder Snow, an Ice-type attack with a 10% chance to freeze.
- Added one pixel of spacing between entries in the Digivolution screen.
- Added scroll indicators and four-row viewport scrolling to digivolution paths larger than 4.
- Updated the status screen to show base stats, permanent Digivolution bonuses, and final totals.
- Adjusted front sprite sizes for Kapurimon, Chuumon, Gizamon
- Adjusted front sprite position for Kapurimon and Hagurumon
- Replaced front sprite for Mushroomon
- Replaced front and back sprites for Agumon.
- Changed Hagurumon's party icon from 16x16 to 32x32px.
- Changed XP Curve ratio from 60% to 80%
- Increased levels of wild encounters on Route 2, 3, 4 and Mt. Moon
- Changed encounter tables for Route 24, 25, 5 and 6 to include Digimon only
- Edited trainer battles in Route 24, 25 and 6
- Increased trainers' digimon level inside Misty gym
- Updated dialogues of various NPCs in Vermilion and Cerulean City.
- Moved the demo boundary NPC and event from Nugget Bridge to Vermilion City.
- Changed the sprite for the PokéCenter, so it says "DIGIC"(enter).
