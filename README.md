# Digimon in Kanto

A Digimon conversion mod for Gen1Recomp. It replaces Pokémon species,
encounters, trainers, terminology, progression, and parts of the interface
with a Digimon-focused experience while retaining the Gen 1 style.

## Current version

Version **0.1.9** is an unfinished demo. An NPC in Vermilion City marks the
current end of the available content.

## Compatibility

- Pokémon Red
- Pokémon Blue
- Pokémon Yellow is not supported
- Mod API 2

## Features

- New Digimon species, sprites, icons, moves, encounters, and trainer parties
- Manual Digivolution and De-Digivolution with branching requirements
- Permanent De-Digivolution stat bonuses, shown alongside base and total stats
- Scrollable Digivolution path lists with requirement indicators
- Reworked experience progression for repeated Digivolution cycles
- Higher-resolution battle, party, status, and Digivolution visuals
- Dark and Steel types plus several new moves
- Digimon terminology and interface changes
- A redesigned DIGI sign for Pokémon Centers
- Reusable TMs

## Installation

Copy the `gen1recomp-digimon` folder into Gen1Recomp's `mods` directory or drag the
downloaded .zip file into the launcher. Open
the mod manager and enable **Digimon in Kanto**. Start a new save for the
intended experience.

## ADDED MOD FEATURES IN THE DEMO:

- new Digimon: 93 Digimon have been added, with modified encounter tables and trainers extending through Celadon City (no game corner)
- Digivolution, inspired by modern Digimon games: No mon evolves with level anymore. There is a new sub-menu when choosing a Digimon in the Party screen the opens the Digivolution window. Every Digimon in In-Training or Rookie Level has at least two Digimon it can evolve two. There are requirements (level, stats and items) a digimon needs to fulfill in order to evolve to another level. Are the requirements not met, a exclamation mark during the preview screen shows a missing requirement. The idea is that a digimon in rookie or champion level NEEDS to devolve several times, because every devolved Digimon gets permanent bonus stats that count to digivolution, depending on the level it had befire devolving. To balance that out, all digimon need 20% less experience to level up (probably will need tweaking)
- added the Dark (SPC) and Steel (PHY) Type, as well as Crunch, Steel Wing, Metal Claw, Metal Sound, Iron Tail and Powder Snow. Bite is now a Dark Move.
- the Salesman in the Mt. Moon Center sells a Betamon for now, will change that later in developement
- words like "POKéMON" and "trainer" have been replaced by "DIGIMON" and "tamer"
- every Digimon has its own party screen icon and colorful sprites
- text borders show little digivices instead of pokeballs
- added a NPC that marks the end of the demo
- on the first status page the player can see the bonus stats a digimon has gotten so far
- a new overlay for battle XP, inspired by modern Pokemon games to prevent having to accept multiple level ups
- Digi-Egg items and item-based Digivolution requirements.
- Automatic level-based evolution has been removed.
