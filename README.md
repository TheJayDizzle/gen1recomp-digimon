# Digimon in Kanto

A Digimon conversion mod for Gen1Recomp. It replaces Pokémon species,
encounters, trainers, terminology, progression, and parts of the interface
with a Digimon-focused experience while retaining the Gen 1 style.

## Current version

Version **0.1.1** is an unfinished demo. The current endpoint is marked by an
NPC near Nugget Bridge in Cerulean City. Content beyond that point is not part
of the current release.

## Compatibility

- Pokémon Red
- Pokémon Blue
- Pokémon Yellow is not supported
- Mod API 2

## Features

- New Digimon species, sprites, icons, moves, encounters, and trainer parties
- Manual Digivolution and De-Digivolution with branching requirements
- Reworked experience progression for repeated Digivolution cycles
- Higher-resolution battle, party, status, and Digivolution visuals
- Digimon terminology and interface changes
- Reusable TMs

## Installation

Copy the `gen1recomp-digimon` folder into Gen1Recomp's `mods` directory. Open
the mod manager and enable **Digimon in Kanto**. Start a new save for the
intended experience.

## Development status

This project is actively in development. Content, balancing, save data, and
interface behavior may change between versions. Bugs and incomplete areas are
expected in the current demo.

See [CHANGELOG.md](CHANGELOG.md) for version history and
